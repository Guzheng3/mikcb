# 工作区变更更新日志（2026-09-01）

> 本文档记录本次本地清理的原因、范围和验证结果。它面向后续开发维护，不是面向用户的新版本发布说明。

## 变更原因

情侣课表、应用内软件更新、请作者喝咖啡三组能力已确认从当前产品方向移除。为避免残留入口、死代码和测试引用继续扩大维护面，本次把它们的主链路、设置项、本地化词条、调试路由、文档和测试一并清理。

## 变更详情

### 移除情侣课表

- 删除情侣课表逻辑、设置页、伴侣课表导入服务、绑定模型、WebDAV 配置与凭据存储、连接底部弹层。
- 清理课表页覆盖层、课程动作菜单、课表切换器、首页导航、调试深链、小组件路由和 Android 侧关联代码。
- 清理存储层、导入导出、同步快照、传输包、LAN 编辑宿主中的伴侣课表数据。
- 同步删除中英日韩等本地化词条、SEO 文档、示例配置与对应测试。
- 由于伴侣导入课表类型不再存在，`activeProfile` 恢复为直接读取当前激活课表；`deleteProfile` 删除当前课表后回退到剩余的第一个课表。

### 移除软件更新

- 删除 `AppUpdateService`、首页更新提示、更新渠道与下载来源枚举，以及相关本地化和测试。
- 清理关于页、超级岛演示页、首页菜单、调试入口和设置持久化中的更新字段。

### 移除请喝咖啡 / 支持作者

- 删除支持作者服务、支持作者页面、捐赠二维码资源、鸣谢数据与鸣谢入口组件。
- 清理关于页、首页菜单、本地化词条、文档构建脚本、资源测试和对应测试。

## 代码库管理

- 新增本地分支 `codex/remove-legacy-features-20260901`，变更按移除、测试稳定化、仓库整理分组提交。
- 将 `.codegraph/` 加入 `.gitignore`，避免本地图谱索引入库。
- 保留未跟踪的 `._cache_adb.exe` 不做提交，该文件来源待用户确认。

## 验证结果

- `flutter analyze --no-pub`：0 error，0 warning；仅保留 15 条既有的 `prefer_initializing_formals` info。
- `flutter test`：1501 通过，3 skip；另有 1 个已知并发环境 flake，单独复跑通过，属于 `course_recolor_sheet_test.dart` 的历史问题。
- 移除后全仓扫描情侣课表、软件更新、请喝咖啡相关标识，源码、测试、工具与 Android 主代码无残留命中。
