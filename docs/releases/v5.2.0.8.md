# v5.2.0.8

- 优化 情侣常驻通知卡片：下拉折叠行改成「课名 · 地点」开头不再被截断，课中时间格换成持续自走的实时读数，应用被系统冻结时也不会停在旧值。
- 优化 情侣桌面卡片：昵称配色改按双方性别固定（男天蓝 / 女粉红），「今天课程已结束」空态文案改为整列居中放大，对方课表未上传时给出明确提示，相关文案补齐英语 / 日语 / 韩语 / 繁体中文。
- 新增 后台受限提醒：系统把应用冻结导致通知读数停滞时，保活页会说明原因并给出直达「耗电管理 · 允许完全后台行为」的入口。
- 优化 情侣登录与课表切换：退出登录后首页立即收回情侣入口与标题，不再残留对方课表的痕迹；退出未能同步到服务器时会有明确提示。
- 移除 情侣叠加视图的「一起上课」图例与叠加自定义颜色设置，配色统一由性别决定。
