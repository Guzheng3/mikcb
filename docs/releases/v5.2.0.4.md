# v5.2.0.4

- 新增 桌面情侣卡片点击课程行：点一下直接进入对应课表并展开这门课的详情（可在情侣课表设置里关闭「点击课程行展开详情」）。
- 新增 「跟随当前课表」开关（情侣课表设置 → 超级岛与提醒归属）：关闭时，超级岛、上课提醒与桌面组件始终按「我的课表」；开启后跟随你当前切换到的那份课表（含对方课表），适合长期用另一份课表当主课表的用法。
- 优化 桌面情侣卡片刷新：当天课程改由原生侧按同一份课表档案重算，长时间不打开 App 也能跨天、跨周、单双周翻转继续推进，卡片不再停在最后一次同步当天的课程。
- 优化 超级岛与提醒归属：灵动岛、上课提醒与今日/统计桌面组件统一按「我的课表」计算——点桌面情侣卡片切到对方课表看一眼，不会再把自己的上课提醒与岛换成对方的；自己的课表不再因此丢失岛显示。
- 优化 流体云摘要态胶囊：按阶段给短文案（课前显示到上课分钟数，课中显示「上课中」，大课内部课间显示到下一节上课），并修正部分 ColorOS 机型上流体云不出卡片的问题。
- 优化 教务导入：整段同为单周或双周的课程，周次统一显示为单双周标记，不再逐周罗列。
- 优化 导入模板：模板示例换成六门更贴近真实课表的课程，便于对照填写。
- 移除 二维码面对面传输：发送端二维码播放页、接收端扫码页与相机权限一并下线，传输改用文件导出 / 导入与 withU 同步。
